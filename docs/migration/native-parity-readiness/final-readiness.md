# Native Final Readiness

Status: free-account simulator release-candidate for build/test gates; not ready for commercial release or runtime distribution signoff.

## Scope
- Current release target: free-account simulator build/test readiness for the native preview apps.
- Current executable gate: `npm run native:readiness`, which writes `docs/migration/native-parity-readiness/native-readiness-free-account.json` and separates free-account build/test evidence from first-release runtime evidence.
- Out of scope for this gate: paid account setup, external store submission, production identity cutover, live credential smoke, and connected-device distribution.

- Expo/RN remains the legacy/reference app and is not deleted in this phase.
