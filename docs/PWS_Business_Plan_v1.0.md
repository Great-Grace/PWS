# PWS (Personal Weather Service) 사업 및 BM 계획서

> **작성일:** 2026-03-29
> **버전:** v1.0
> **서비스명:** PWS — 나만의 체감날씨 예측 서비스

---

## 1. 서비스 개요

PWS는 **개인 맞춤형 체감날씨 예측** 앱으로, 온디바이스 머신러닝(퍼셉트론)이 사용자 피드백을 학습하여 기존 날씨 앱이 제공하지 못하는 **"나에게 맞는 체감온도"**를 예측합니다.

### 핵심 차별화

| 기존 날씨 앱 | PWS |
|---|---|
| 모든 사용자에게 동일한 체감온도 | 개인별 체감 예측 (BMI, 생활패턴, 피드백 학습) |
| 풍속 기반 고정 공식 (Wind Chill / Heat Index) | 11차원 피처 벡터 + 온디바이스 SGD 학습 |
| 날씨 정보 "표시" | 날씨 정보 "예측 + 행동 추천" |
| 미세먼지/UV 부가정보 | 시간대별 옷차림 + 준비물 추천 (유료) |

### 수익 모델 (듀얼 레버)

- **무료 유저:** 배너/네이티브 광고 수익
- **유료 구독 (₩3,900/월):** LLM 기반 고도화 분석 + 개인화 옷차림 추천

#### 날씨 API 비용 최적화

PWS는 **2단계 캐싱**으로 API 호출을 최소화합니다:
- 좌표 1km 그리드 반올림 → 같은 동네 유저 캐시 공유
- 30분 TTL → 동일 위치 반복 호출 차단
- **실효 API 호출:** 유저당 ~0.3~0.5회/일 (캐시 히트율 80%+)

### 2.2 유료 모델 — LLM API 비용 분석

#### 호출 구조

유료 유저 1명당 **1일 1회** LLM 호출:

```
[입력 패키지]                    ~640 tokens
├── 시스템 프롬프트              ~200 tokens  (역할 + 출력 포맷 정의)
├── 가중치 해석 프로필            ~80 tokens   ("습도 민감, 추위에 약함...")
├── 당일 날씨 벡터 (3슬롯)       ~100 tokens  (temp/humidity/wind/tmrt/precip)
├── 퍼셉트론 예측값              ~60 tokens   (morning: 2.8, afternoon: 4.1, ...)
├── 생활 패턴 요약              ~100 tokens  (commute/work_env/exercise)
└── 데일리 이벤트               ~100 tokens  (사용자 자유 입력)

[출력]                          ~350 tokens
├── 하루 한 문장 요약
├── 3슬롯 옷차림 추천
├── 준비물 리스트
└── 이벤트 맞춤 팁
```

**총 토큰:** 입력 640 + 출력 350 = **~990 tokens/call**

#### 모델별 비용 비교

| 모델 | 입력 단가 ($/MTok) | 출력 단가 ($/MTok) | 1회 호출 비용 | 월 비용/유저 (30일) | 품질 | 평가 |
|---|---|---|---|---|---|---|
| GPT-4o | $2.50 | $10.00 | $0.0051 | **₩211** | 100% | 과잉 스펙 |
| Claude Sonnet 4.6 | $3.00 | $15.00 | $0.0072 | **₩297** | 100% | 과잉 스펙 |
| **Claude Haiku 4.5** | **$0.80** | **$4.00** | **$0.0019** | **₩80** | **95%** | **최적 선택** |

#### 권장 모델: Claude Haiku 4.5

**선정 근거:**
1. **한국어 품질:** Anthropic 모델 중 한국어 자연어 생성 품질 우수
2. **비용 효율:** GPT-4o 대비 1/3 비용으로 95% 품질
3. **구조화 출력:** JSON 출력 포맷 안정적 준수
4. **응답 속도:** ~0.5초 (체감 즉시 응답)
5. **컨텍스트:** 200K window → 향후 과거 피드백 이력 포함 가능

## 9. BM 실행 로드맵

### Phase 1: MVP 출시 + 광고 수익화 (Month 1-3)

- 무료 앱 출시 (온디바이스 퍼셉트론)

- RevenueCat 인앱 결제

### Phase 3: 성장 + 최적화 (Month 7-12)

- 전환율 최적화 (무료 체험, 옷차림 미리보기)
- 연간 구독 프로모션
- 목표: 10K~30K MAU / 5% 전환 → 월 ₩2.1M~6.4M

### Phase 4: 스케일 (Year 2)

- 데이터 기반 부가 수익 (익명화 인사이트 → 패션/리테일 B2B)
